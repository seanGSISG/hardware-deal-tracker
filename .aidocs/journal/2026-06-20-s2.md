# Session 2 — Cascade-delete fix + remove RTX6000Ada/L4 + dark-theme cards

Three issues Sean hit on the live dashboard: couldn't delete tracked items, wanted
two GPUs gone, and the deal cards were blinding white on the dark shell.

- **Fixed "won't delete tracked items"** (root cause: FK violations) — all 7 child
  tables (listings, price_history, listing_scores, alerts, ai_analyses,
  item_price_baselines, community_signal_leads) referenced `tracked_items` with
  **NO ACTION**, so `db.delete(item)` blew up on any item that had children.
  - Alembic migration `cascade_delete_tracked_items` → recreates the 7 FKs with
    **ON DELETE CASCADE**; added `ondelete="CASCADE"` to the model FK columns (so
    sqlite create_all cascades too) + `cascade="all, delete-orphan", passive_deletes=True`
    on the `listings`/`price_history` relationships (else the ORM tries to NULL the
    NOT-NULL `price_history.tracked_item_id` before the DB cascade fires).
  - Verified live through the API: `POST /api/v1/items` (200, id 62) then
    `DELETE /api/v1/items/62` (200, "Item deleted") — **add AND delete both work**.
- **Removed NVIDIA RTX 6000 Ada 48GB + NVIDIA L4 24GB** — pulled RTX 6000 Ada from
  `catalog.py` (item + pcpp mapping + min_score; 24 items now), regenerated seed,
  and `DELETE`d both from the live DB (cascade cleaned their child rows). Updated
  pcpp test (7 mapped) and the migration-head test.
- **Dark-themed the cards** — the app already ships a full dark theme (Tailwind v4
  `@theme` tokens: `--color-surface/-text/-border`, used by the sidebar) but every
  content page hardcoded `bg-white` + `text-slate-*`, so cards were white and some
  headings were dark-on-dark. Swapped to theme tokens across
  deals/items/add/history/alerts/community/dashboard/settings (login left alone).
- **Full backend suite: 346 passed, 6 skipped.** Two commits: `ad868e4` (backend),
  `47db072` (frontend). Backend + frontend images rebuilt & recreated; both healthy.
- **Alerts state (answer to Sean's question):** **Telegram = ON/working** (chat
  8304825231, min_score 60, bot @lsdmt_me_homelab_bot). **Email = transport exists
  but OFF** (`email_enabled=false`, no `email_address`). **Ntfy = not implemented**
  (only telegram + email transports exist; homelab ntfy at ntfy.lab.lsdmt.me is unused).

### Lessons Learned
- **`db.delete()` needs BOTH DB-level ON DELETE CASCADE and ORM `passive_deletes=True`**
  when a child FK is NOT NULL — otherwise SQLAlchemy's default "NULL the child FK"
  runs first and violates the NOT NULL before the DB cascade ever fires.
- **The instrumented Chrome (CDP) won't complete the login click** (renderer throttled,
  stays on /login) — verify auth-gated flows with `curl` + bundle inspection, not the
  automation browser. Same artifact seen in s-DNS work.
- This dashboard was built light-theme-first on top of a dark global theme — any new
  page must use `bg-surface`/`text-text`/`border-border`, never `bg-white`/`text-slate-*`.
