### Lessons Learned
- `seed_data_v2.sql` is GENERATED from `catalog.py` — never hand-edit; `make seed-regen` (`uv run scripts/generate_seed.py`) is the only path. `min_deal_score`/`pcpp_product_id` are stamped at import time, so the catalog stays the single source of truth.
- Adding N memory SKUs is API-budget-bound: each item at interval S adds 86400/S calls/day against eBay's 5k/day cap — pick the poll tier from the budget, not the item's volatility.
