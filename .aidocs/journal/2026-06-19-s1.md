### Lessons Learned
- **The tracker's `.env` had a `your-bot-token` placeholder** — that was the real reason it never alerted. The DB toggles being off was secondary. Always check the *token*, not just the enable flags.
- **`docker restart` reuses stale container env** — it does NOT re-read `.env`. Must `docker compose up -d <service>` to pick up env_file changes. Wasted one cycle confirming `bot_id=your-bot-token` after a plain restart.
- **`USE_MOCK_EBAY=false` confirmed** — alerts are live-market, not mock. Worth verifying before trusting any "deal."
- **The seed parity test (`test_seed_parity.py`) splits on the first `;`** — so any semicolon inside a catalog `notes` string truncates the parse and fails the test. Catalog notes must be semicolon-free (use periods/commas).
- This repo had **no `.aidocs/journal/` system** before today — created manually. Consider running the `journal-bootstrap` skill to add the `journal.py` helper + templates for sustainability.
